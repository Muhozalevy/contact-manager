#  Contact Manager - React State Mastery

Une application de gestion de contacts robuste conçue pour démontrer une maîtrise avancée des hooks React, en particulier la gestion d'états complexes et l'immuabilité des données.

## Objectifs du Projet

L'enjeu principal de ce projet était de gérer un cycle CRUD complet tout en maintenant un code propre et performant :
- **Maîtrise de `useState`** : Gestion de formulaires contrôlés et de listes d'objets.
- **Logique d'Immuabilité** : Mise à jour sécurisée des tableaux d'objets (utilisation de `.filter()`, `.map()` et du spread operator `...`).
- **Expérience Utilisateur** : Feedback visuel lors de l'ajout ou de la modification.

## Fonctionnalités

- **Ajouter** : Création de nouveaux contacts avec validation de champs.
- **Modifier** : Passage d'un contact en "mode édition" pour mettre à jour ses informations en temps réel.
- **Supprimer** : Retrait instantané de la liste avec confirmation.
- **Recherche** : Filtrage dynamique des contacts par nom ou téléphone.

##  Stack Technique

- **Framework** : React (Vite)
- **State Management** : React Hooks (`useState`,)
- **Icons** : React-Icons (Lucide/FontAwesome)
- **Styling** : CSS Modules / Flexbox
